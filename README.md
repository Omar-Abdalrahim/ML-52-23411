# 🧠 Machine Learning Projects — Classification & Clustering

A collection of machine learning projects focused on **classification** and **clustering** across multiple datasets, including a full classification pipeline developed for the **WiDS Datathon 2025 Kaggle Competition**. Each project includes end-to-end data preparation, model experimentation, performance evaluation, and insight extraction.

---

## 🚀 Techniques Used

### 🔹 Clustering

* **K-Means**
* **Hierarchical Clustering**
* **DBSCAN**

### 🔹 Classification ([WiDS Kaggle Competition](https://www.kaggle.com/competitions/widsdatathon2025/overview))

* **Logistic Regression**
* **Decision Trees**
* **Random Forest**
* **XGBoost**
* **Neural Networks**

---

## 📊 Model Evaluation

### **Classification Metrics**

* **ROC Curve & AUC**
* **F1 Score**
* **Accuracy**
* **Confusion Matrix**

Each model was benchmarked and compared across the above metrics to identify the optimal classifier for the Kaggle problem.

### **Clustering Metrics**

* **Silhouette Score**
* **Davies–Bouldin (DB) Score**

Used these metrics to evaluate cluster cohesion, separation, and overall clustering quality across algorithms.
